# Review Theme Rubric (Stage 3)

AI-drafted by Claude on 2026-10-09, to be checked by Disha (guide p.10). A review can carry several codes. Code only what the text says; never infer skin conditions, causes or efficacy.

| Code | Theme | Code it when the review says... | Do NOT code when... |
|---|---|---|---|
| T1 | Breakouts / clogged pores | it caused acne, bumps, cysts, clogged pores | it says it did NOT break them out (that is a positive) or only repeats hearsay ("I heard it clogs pores") |
| T2 | Irritation / reaction | burning, stinging, redness, itching, rash, hives, swelling, "allergic" | the reviewer only says "not for sensitive skin" with no described reaction (flag as ambiguous) |
| T3 | Dryness / not hydrating enough | it dried skin out, felt tight or stripped, flaking, or did not hydrate | dryness is the reviewer's skin type, not an effect of the product |
| T4 | Texture / application | pilling, sits on top, heavy, greasy, does not absorb, peels under makeup | texture is praised |
| T5 | Scent | the smell is described (good or bad) | "unscented" with no opinion |
| T6 | Price / value | price, worth the money, cost per use, overpriced | "don't waste your money" used only as an emphasis with no price point (flag) |
| T7 | Packaging / fill | container, pump, tube, seal, refill, how full it is | |
| T8 | Cleansing / makeup removal (cleanser only) | removes or fails to remove makeup, lather, feeling clean | |
| T9 | Perceived formula or packaging change | "they changed it", "new formula", "used to love it" | |
| T10 | Hype / social influence | TikTok, influencers, social media, "overhyped" | ordinary "I read reviews" |
| T11 | Received as sample or gift | free sample, advent calendar, points sample, gift set | the reviewer bought a mini or travel size |
| T13 | Routine / layering problem (added by Disha in the human check) | pilling, curdling or burning happens only when used with other skincare (serum, retinol, acne treatment) | the problem happens on clean skin, or only with makeup (that stays T4) |
| T12 | No visible result | "does nothing", "no difference", "nothing special" | |

**Ambiguity rule:** if a code depends on interpretation, apply it and mark the row `ambiguous = yes` with a one-line reason. These rows go into the 20-row human check first.

**Positive codes for 4-5 star reviews** use the same themes with a `+` sign (for example `T5+` = likes the scent, `T1+` = says it did not cause breakouts, `T8+` = removes makeup well).

**Rules set in the human check (2026-10-09, Disha):** a reported reaction counts even if it happened to someone else the reviewer mentions; enlarged pores or new oiliness count as T1; pilling or peeling with makeup stays T4; pilling, curdling or burning tied to other skincare is T13.
